Why is my agent expensive?

A tool-calling agent replays the whole conversation every turn. So input tokens compound, and cost grows quadratically with the number of turns — not linearly. Drag the sliders and watch where the money actually goes.

The math

At turn t, the model is sent the system prompt plus everything that came before: input(t) = base + (t−1)·(output + tool_result) + tool_result. Summed over N turns, the replayed history term grows like N². Output is billed once per turn.

Why it matters

Two levers dominate your bill: turns (history compounds) and tool result size (it's replayed every turn after). Truncating tool payloads and enabling prompt caching — which bills the repeated prefix at ~10% — are the highest-leverage fixes. Most "why is my agent so expensive" surprises are one of these two.
